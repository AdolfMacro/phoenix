# phoenix

**داده را داخل تصاویر PNG پنهان کنید.** یک ابزار استگانوگرافی با رابط گرافیکی تمام‌صفحه و حال‌وهوای ترمینال.

پhoeنیک دادهٔ شما را بعد از بلاک `IEND` یک تصویر PNG اضافه می‌کند. خودِ داده‌های تصویر دست‌نخورده باقی می‌مانند، بنابراین تصویر میزبان در هر نمایشگری عادی باز می‌شود و در صورت خواست می‌توانید محتوا را با یک کلید Fernet رمزگذاری کنید.

```
phoenix          # باز کردن رابط گرافیکی، تمام‌صفحه
phoenix --help
phoenix --version
phoenix --check  # مقایسه با نسخهٔ منتشرشده
```

![رابط گرافیکی Phoenix](https://github.com/AdolfMacro/phoenix/blob/main/screenshots/1.png?raw=true)

## این کار چطور انجام می‌شود؟

یک فایل PNG دنباله‌ای از بلاک‌هاست:

```
89 50 4E 47 0D 0A 1A 0A   امضای فایل
IHDR ...                    سرآیند تصویر
IDAT ...                    پیکسل‌های فشرده
IEND AE 42 60 82            نشانهٔ پایان
<دادهٔ شما>                 این‌جا اضافه می‌شود
```

در `phoenix/core.py` ساختار واقعی بلاک‌ها قدم‌به‌قدم پیمایش می‌شود — فیلد چهار بایتی طول هر بلاک خوانده می‌شود و مکان‌نما جلو می‌رود — تا به `IEND` برسد؛ سپس هر چیزی که بعد از آن آمده به‌عنوان دادهٔ پنهان برگردانده می‌شود.

پیمایش ساختار به‌جای جست‌وجوی الگوی بایتی `IEND` دو فایدهٔ مهم دارد:

- داده‌ای که خودش شامل الگوی `IEND` باشد **سالم و کامل** ذخیره و بازخوانی می‌شود، نه اینکه در نخستین تطابق بی‌صدا بریده شود.
- فایل بریده، خراب یا غیر-PNG به‌جای خطای خام `IndexError` با پیامی روشن رد می‌شود.

اگر روی تصویری که از قبل داده دارد دوباره عمل کنید، دادهٔ دومی به انتها اضافه می‌شود و هنگام خواندن، آخرین داده برگردانده می‌شود. نوشتن روی همان فایلی که در حال خواندنش هستید مجاز نیست.

## نصب

```bash
git clone https://github.com/AdolfMacro/phoenix.git
cd phoenix
bash installer.sh
```

اسکریپت را با **کاربر عادی** اجرا کنید — خودش برای `sudo` از شما اجازه می‌گیرد. کد را در `/usr/src/phoenix` نصب می‌کند و یک دستور راه‌انداز در `/usr/local/bin/phoenix` می‌سازد.

### وابستگی‌ها و قاعدهٔ PEP 668

در نسخه‌های تازهٔ دبیان، اوبونتو، فدورا و آرچ، مفسر سیستم «مدیریت‌شده بیرونی» علامت خورده است؛ بنابراین `pip install` روی آن — با `--user` یا بدون آن — با خطای `externally-managed-environment` رد می‌شود. پhoeنیک اصلاً چنین تلاشی نمی‌کند و نخستین گزینه‌ای را که جواب بدهد انتخاب می‌کند:

۱. **مفسری که همین حالا هر دو بسته را دارد.** در این حالت چیزی نصب نمی‌شود.
۲. **بسته‌های توزیع**، اگر مدیر بسته در دسترس باشد (`apt-get`، `dnf`، `pacman`، `zypper`): یعنی `python3-cryptography` و `python3-pyqt6`.
۳. **یک محیط مجازی خصوصی** در مسیر `/usr/src/phoenix/.venv`.

برای انتخاب دستی:

```bash
PHOENIX_DEPS=venv    bash installer.sh   # همیشه محیط مجازی
PHOENIX_DEPS=distro  bash installer.sh   # فقط بسته‌های توزیع
PHOENIX_DEPS=system  bash installer.sh   # فقط مفسری که از پیش کار می‌کند
PHOENIX_PYTHON=/path/to/python3 bash installer.sh
PHOENIX_PREFIX=~/.local/share/phoenix PHOENIX_BINDIR=~/.local/bin bash installer.sh
```

اجرای دوبارهٔ نصب‌کننده بی‌خطر است: محیط مجازی موجود دوباره ساخته نمی‌شود و دستور راه‌انداز همیشه مسیر مطلق مفسر را در خود ذخیره می‌کند.

### حذف نصب

```bash
sudo rm -rf /usr/src/phoenix /usr/local/bin/phoenix
sudo rm -rf /usr/src/phoenix/.venv      # فقط اگر محیط مجازی ساخته شده بود
```

## کار با رابط گرافیکی

پنجره **تمام‌صفحه** باز می‌شود. چهار صفحه از منوی سمت چپ در دسترس است.

| کلید | کار |
| --- | --- |
| `1` تا `5` | جابه‌جایی میان صفحه‌ها (۱ تا ۴ صفحه، ۵ خروج) |
| `F11` | جابه‌جایی میان تمام‌صفحه و پنجرهٔ عادی |
| `ESC` | خروج از حالت تمام‌صفحه |
| `CTRL+Q` | بستن برنامه |

`CTRL+C` هم برنامه را تمیز و بدون هیچ خطایی می‌بندد.

### ۱ · پنهان‌سازی

یک تصویر PNG انتخاب کنید، متن را بنویسید یا از فایل بارگذاری کنید و خروجی را بنویسید. با زدن گزینهٔ **رمزگذاری داده با کلید جدید Fernet** کلیدی ساخته می‌شود که فقط یک بار نشان داده می‌شود — **آن را نگه دارید؛ تنها راه بازگرداندن داده همین است.** نام فایل خروجی به‌صورت `<name>_phoenix.png` پیشنهاد می‌شود.

### ۲ · استخراج

تصویر ساخته‌شده با پhoeنیک را انتخاب کنید. خط اطلاعات، اندازهٔ تصویر، اندازهٔ دادهٔ پنهان و رمز بودن یا نبودن آن را نشان می‌دهد. اگر کلید استفاده شده، گزینهٔ **دادهٔ پنهان رمزگذاری شده است** را بزنید و کلید را بچسبانید. متن بازیابی‌شده را می‌توانید کپی یا ذخیره کنید.

### ۳ · توسعه‌دهنده

اطلاعات نویسنده، پیوندها و توضیح کوتاهی دربارهٔ موتور کار.

### ۴ · به‌روزرسانی

نسخهٔ محلی `VERSION.txt` را با نسخهٔ منتشرشده روی گیت‌هاب مقایسه می‌کند و می‌گوید به‌روز هستید یا عقب یا جلوتر. برای اعمال به‌روزرسانی، نصب‌کننده دوباره اجرا می‌شود و به `sudo` نیاز دارد.

کنسول پایین پنجره، هر عملیات را همراه با ساعت ثبت می‌کند.

## استفادهٔ مستقیم از موتور

بستهٔ `phoenix.core` هیچ وابستگی‌ای به رابط گرافیکی ندارد و جز `cryptography` چیز دیگری از بیرون نمی‌آورد:

```python
from phoenix import core

key = core.generate_key()                       # ۴۴ نویسهٔ امن برای نشانی اینترنتی
token = core.encrypt_payload("secret", key)     # یک توکن Fernet برمی‌گرداند

core.bind("cover.png", "cover_phoenix.png", token)   # تعداد بایت نوشته‌شده
core.read("cover_phoenix.png")                       # خودِ توکن
core.read("cover_phoenix.png", key)                  # «secret»
```

در `read(source, key=None)` نبودن کلید با خالی بودنش فرق دارد: مقدار `None` یعنی «این داده رمز نشده است»، ولی هر رشتهٔ دیگری — حتی `""` — یعنی «با این کلید رمزگشایی کن». به این ترتیب کلیدِ جاافتاده گزارش می‌شود و دادهٔ خام به‌جای پیام نشان داده نمی‌شود.

هر خطا `PhoenixError` با پیامی می‌دهد که برای انسان نوشته شده است:

```python
>>> core.read("notes.txt")
PhoenixError: This file is not a PNG image. Only PNG files are supported.

>>> core.read("bound.png", "wrong-key")
PhoenixError: Wrong decryption key, or the payload was altered.
```

### رابط برنامه‌نویسی

| تابع | کار |
| --- | --- |
| `bind(source, destination, payload) -> int` | داده را در رونوشتی از تصویر می‌نویسد و تعداد بایت‌ها را برمی‌گرداند |
| `read(source, key=None) -> str` | داده را برمی‌گرداند و در صورت داشتن کلید، رمزگشایی می‌کند |
| `inspect(source) -> dict` | اندازهٔ تصویر، اندازهٔ داده و رمز بودن یا نبودن آن |
| `is_png(path) -> bool` | بررسی ساختاری، بدون خطا |
| `validate_png(path) -> Path` | بررسی ساختاری، با پرتاب `PhoenixError` |
| `generate_key() -> str` | کلید جدید Fernet |
| `encrypt_payload(plaintext, key) -> str` | رمزگذاری به توکن Fernet |
| `decrypt_payload(token, key) -> str` | رمزگشایی توکن Fernet |
| `find_payload(blob) -> bytes` | استخراج داده از بایت‌های خام فایل |

محدودیت‌های ایمنی: `MAX_IMAGE_BYTES` برابر ۲۵۶ مگابایت و `MAX_PAYLOAD_BYTES` برابر ۶۴ مگابایت است؛ ورودی‌های بزرگ‌تر به‌جای بارگذاری کورکورانه در حافظه، رد می‌شوند.

## نکات امنیتی

پیش از تکیه بر این ابزار، این بخش را بخوانید.

- **داده از کسی که دقیق نگاه کند پنهان نیست.** داده بعد از آخرین بلاک قرار می‌گیرد، پس `strings`، ویرایشگر هگز یا هر اسکریپتی که از `IEND` به بعد را بخواند آن را پیدا می‌کند. استگانوگرافی داده را از چشم یک ناظر پنهان می‌کند، نه از یک تحلیل‌گر.
- **رمزگذاری همان بخشی است که اهمیت دارد.** با زدن گزینهٔ **رمزگذاری داده**، داده با Fernet ذخیره می‌شود: AES-128-CBC همراه با احراز‌گر HMAC-SHA256، کلیدها ۳۲ بایتی‌اند و کلید اشتباه یا دادهٔ دست‌خورده رد می‌شود، نه اینکه به‌صورت داده‌های بی‌معنا برگردد.
- **گم کردن کلید یعنی از دست دادن داده.** هیچ راه بازیابی و هیچ نسخهٔ پشتیبان از کلید وجود ندارد. در هر عملیات پنهان‌سازی کلید تازه‌ای ساخته و فقط یک بار نشان داده می‌شود.
- **کلید هیچ‌جا ذخیره نمی‌شود**؛ نه در تصویر و نه در `VERSION.txt`. رابط گرافیکی آن را فقط در حافظهٔ موقت نگه می‌دارد و به‌جز کپی در حافظه، چیزی روی دیسک نوشته نمی‌شود.
- **کلید هم اگر بی‌احتیاط نگه داشته شود، لو می‌رود.** با آن مثل رمز عبور رفتار کنید.
- تصاویر توسط Qt برای پنجره‌های انتخاب فایل باز می‌شوند؛ پhoeنیک هیچ چیزی را جایی بارگذاری نمی‌کند.

## نسخه‌بندی

نسخه در `VERSION.txt` نگهداری می‌شود و تنها مرجع بسته، عنوان پنجره و خروجی `phoenix --version` است.

مقایسهٔ نسخه‌ها بر پایهٔ رقم‌های آن‌ها انجام می‌شود (`0.2:1` یعنی `[0, 2, 1]`)، نه به‌صورت رشته؛ بنابراین `0.10` درست بالاتر از `0.9` و `0.2:1` بالاتر از `0.0.1:0` قرار می‌گیرد. نسخهٔ منتشرشده از نشانی زیر خوانده می‌شود:

```
https://raw.githubusercontent.com/AdolfMacro/phoenix/main/VERSION.txt
```

`VERSION.txt`، `phoenix.VERSION` و ثابت داخل `main.py` را با هم تغییر دهید.

## اجرا از روی کلون

```bash
python3 main.py           # رابط گرافیکی
python3 main.py --version
python3 main.py --check
```

به `cryptography` و `PyQt6` در همان مفسری نیاز دارد که اجرا می‌کنید. اگر PyQt6 نصب نباشد، `main.py` به‌جای `ImportError` خام، دستور نصب دقیق را چاپ می‌کند.

## نکات کارایی

تنها بخش واقعاً پرهزینهٔ رابط گرافیکی، انیمیشن تمام‌صفحهٔ پس‌زمینه است. برای ارزان نگه‌داشتن آن:

- تیتر درخشان فقط **یک بار** در یک pixmap رسم می‌شود و بعداً فقط تصویرسازی می‌شود؛ لرزش هم یک تصویرسازی با شفافیت متغیر است.
- اسکن‌لاین‌ها یک لایهٔ ذخیره‌شده‌اند که در یک فراخوانی روی صفحه منتقل می‌شود.
- دکمه‌ها تصویر خود را برای هر وضعیت (Hover، فشردن، غیرفعال، فوکوس) ذخیره می‌کنند.
- باران در بافری با سقف ۱۶۰۰×۹۰۰ رسم می‌شود و سپس بزرگ می‌شود، پس هزینه با بزرگی مانیتور رشد نمی‌کند؛ همچنین **نرخ فریمش را خودش تنظیم می‌کند** و اگر یک فریم بیش از ۹ میلی‌ثانیه طول بکشد، کندتر می‌شود.

اندازه‌گیری روی پنجرهٔ تمام‌صفحهٔ بی‌کار با ابعاد ۲۳۰۴×۱۲۹۶: بازترسیم کامل حدود ۱۴ میلی‌ثانیه طول می‌کشد و برنامه هنگام انیمیشن حدود یک‌سوم یک هستهٔ پردازنده را مصرف می‌کند.

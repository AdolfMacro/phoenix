# phoenix

**داده را داخل تصاویر PNG پنهان کنید.**

Phoenix یک ابزار استگانوگرافی با رابط گرافیکی تمام‌صفحه و ظاهر ترمینالی است.

داده در Phoenix بعد از بلاک `IEND` فایل PNG قرار می‌گیرد. محتوای اصلی تصویر تغییر نمی‌کند، بنابراین تصویر همچنان در نمایشگرهای معمولی بدون مشکل باز می‌شود. در صورت نیاز می‌توانید داده را با یک کلید Fernet هم رمزگذاری کنید.

```bash
phoenix          # اجرای رابط گرافیکی در حالت تمام‌صفحه
phoenix --help
phoenix --version
phoenix --check  # بررسی نسخه در برابر نسخه منتشرشده
```

![رابط گرافیکی Phoenix](https://github.com/AdolfMacro/phoenix/blob/main/screenshots/1.png?raw=true)

## چطور کار می‌کند؟

یک فایل PNG از چند بلاک تشکیل شده است:

```text
89 50 4E 47 0D 0A 1A 0A   امضای فایل
IHDR ...                    اطلاعات اصلی تصویر
IDAT ...                    داده‌های فشرده تصویر
IEND AE 42 60 82            پایان فایل PNG
<داده شما>                 داده در این قسمت قرار می‌گیرد
```

در `phoenix/core.py` بلاک‌های PNG به‌ترتیب خوانده می‌شوند. طول هر بلاک از فیلد چهار بایتی آن گرفته می‌شود و مکان‌نما تا رسیدن به `IEND` جلو می‌رود. هر چیزی که بعد از `IEND` باشد، به‌عنوان دادهٔ پنهان در نظر گرفته می‌شود.

این روش از جست‌وجوی سادهٔ عبارت `IEND` بهتر است، چون:

* اگر خود داده شامل الگوی `IEND` باشد، هنگام استخراج قطع نمی‌شود.
* فایل ناقص، خراب یا غیر-PNG با یک خطای مشخص رد می‌شود و به خطاهایی مثل `IndexError` ختم نمی‌شود.

اگر روی تصویری که از قبل داده دارد دوباره داده‌ای بنویسید، دادهٔ جدید به انتهای فایل اضافه می‌شود. هنگام خواندن، آخرین داده برگردانده می‌شود.

نوشتن روی همان فایلی که در حال خواندن آن هستید مجاز نیست.

## نصب

```bash
git clone https://github.com/AdolfMacro/phoenix.git
cd phoenix
bash installer.sh
```

نصب‌کننده را با **کاربر عادی** اجرا کنید. اگر نیاز باشد، خودش برای `sudo` از شما اجازه می‌گیرد.

به‌صورت پیش‌فرض برنامه در `/usr/src/phoenix` نصب می‌شود و دستور `phoenix` در `/usr/local/bin/phoenix` قرار می‌گیرد.

### وابستگی‌ها و PEP 668

در نسخه‌های جدید Debian، Ubuntu، Fedora و Arch، پایتون سیستم به‌عنوان محیط مدیریت‌شده علامت‌گذاری شده است. در این حالت `pip install` روی Python سیستم، حتی با `--user`، می‌تواند با خطای `externally-managed-environment` متوقف شود.

Phoenix این مشکل را دور می‌زند و این ترتیب را امتحان می‌کند:

1. **پایتونی که وابستگی‌ها را از قبل دارد.** چیزی نصب نمی‌شود.
2. **بسته‌های سیستم‌عامل**، در صورت وجود مدیر بسته (`apt-get`، `dnf`، `pacman` یا `zypper`).
3. **محیط مجازی خصوصی** در `/usr/src/phoenix/.venv`.

اگر می‌خواهید روش نصب را خودتان مشخص کنید:

```bash
PHOENIX_DEPS=venv    bash installer.sh   # همیشه محیط مجازی
PHOENIX_DEPS=distro  bash installer.sh   # فقط بسته‌های توزیع
PHOENIX_DEPS=system  bash installer.sh   # فقط مفسر موجود
PHOENIX_PYTHON=/path/to/python3 bash installer.sh
PHOENIX_PREFIX=~/.local/share/phoenix PHOENIX_BINDIR=~/.local/bin bash installer.sh
```

اجرای دوبارهٔ نصب‌کننده مشکلی ایجاد نمی‌کند. اگر محیط مجازی از قبل وجود داشته باشد، دوباره ساخته نمی‌شود و launcher همیشه مسیر کامل مفسر را نگه می‌دارد.

### حذف نصب

```bash
sudo rm -rf /usr/src/phoenix /usr/local/bin/phoenix
sudo rm -rf /usr/src/phoenix/.venv      # اگر محیط مجازی ساخته شده بود
```

## کار با رابط گرافیکی

برنامه به‌صورت تمام‌صفحه اجرا می‌شود و چهار صفحه از منوی سمت چپ دارد.

| کلید       | عملکرد                                    |
| ---------- | ----------------------------------------- |
| `1` تا `5` | رفتن به صفحه‌های ۱ تا ۴؛ کلید ۵ برای خروج |
| `F11`      | جابه‌جایی بین حالت تمام‌صفحه و پنجره‌ای   |
| `ESC`      | خروج از حالت تمام‌صفحه                    |
| `CTRL+Q`   | بستن برنامه                               |

`CTRL+C` هم برنامه را بدون خطای اضافی می‌بندد.

### ۱ · پنهان‌سازی

یک فایل PNG انتخاب کنید، متن را وارد کنید یا از یک فایل بخوانید و سپس فایل خروجی را بسازید.

اگر گزینهٔ **رمزگذاری داده با کلید جدید Fernet** را فعال کنید، Phoenix یک کلید جدید می‌سازد و فقط یک بار آن را نشان می‌دهد.

**کلید را نگه دارید. بدون آن امکان بازیابی داده وجود ندارد.**

نام فایل خروجی به‌صورت `<name>_phoenix.png` پیشنهاد می‌شود.

### ۲ · استخراج

تصویر ساخته‌شده با Phoenix را انتخاب کنید.

اطلاعات بالای صفحه اندازهٔ تصویر، اندازهٔ دادهٔ پنهان و وضعیت رمزگذاری را نشان می‌دهد.

اگر داده رمزگذاری شده است، گزینهٔ **دادهٔ پنهان رمزگذاری شده است** را فعال کنید و کلید را وارد کنید. بعد از استخراج می‌توانید متن را کپی یا ذخیره کنید.

### ۳ · توسعه‌دهنده

اطلاعات نویسنده، لینک‌ها و توضیح کوتاهی دربارهٔ موتور Phoenix.

### ۴ · به‌روزرسانی

نسخهٔ موجود در `VERSION.txt` را با نسخهٔ منتشرشده در GitHub مقایسه می‌کند و مشخص می‌کند نسخهٔ فعلی به‌روز است یا نه.

برای نصب نسخهٔ جدید، نصب‌کننده دوباره اجرا می‌شود و در این مرحله به `sudo` نیاز است.

کنسول پایین برنامه هم عملیات انجام‌شده را همراه با زمان ثبت می‌کند.

## استفاده مستقیم از موتور

`phoenix.core` مستقل از رابط گرافیکی است و به‌جز `cryptography` وابستگی خارجی دیگری ندارد:

```python
from phoenix import core

key = core.generate_key()                       # ۴۴ نویسهٔ امن برای نشانی اینترنتی
token = core.encrypt_payload("secret", key)     # ساخت توکن Fernet

core.bind("cover.png", "cover_phoenix.png", token)   # تعداد بایت نوشته‌شده
core.read("cover_phoenix.png")                       # خود توکن
core.read("cover_phoenix.png", key)                  # "secret"
```

در `read(source, key=None)`، مقدار `None` با کلید خالی فرق دارد.

`None` یعنی داده رمزگذاری نشده است. هر رشتهٔ دیگری، حتی `""`، به‌عنوان کلید رمزگشایی استفاده می‌شود.

در نتیجه اگر کلید اشتباه باشد، خطا به‌درستی گزارش می‌شود و دادهٔ خام نمایش داده نمی‌شود.

خطاها با `PhoenixError` برگردانده می‌شوند:

```python
>>> core.read("notes.txt")
PhoenixError: This file is not a PNG image. Only PNG files are supported.

>>> core.read("bound.png", "wrong-key")
PhoenixError: Wrong decryption key, or the payload was altered.
```

### API

| تابع                                        | عملکرد                                                             |
| ------------------------------------------- | ------------------------------------------------------------------ |
| `bind(source, destination, payload) -> int` | داده را در یک کپی از تصویر می‌نویسد و تعداد بایت‌ها را برمی‌گرداند |
| `read(source, key=None) -> str`             | داده را می‌خواند و در صورت وجود کلید، آن را رمزگشایی می‌کند        |
| `inspect(source) -> dict`                   | اندازهٔ تصویر، اندازهٔ داده و وضعیت رمزگذاری را برمی‌گرداند        |
| `is_png(path) -> bool`                      | ساختار PNG را بررسی می‌کند                                         |
| `validate_png(path) -> Path`                | ساختار PNG را بررسی می‌کند و در صورت مشکل `PhoenixError` می‌دهد    |
| `generate_key() -> str`                     | یک کلید جدید Fernet می‌سازد                                        |
| `encrypt_payload(plaintext, key) -> str`    | متن را به توکن Fernet تبدیل می‌کند                                 |
| `decrypt_payload(token, key) -> str`        | توکن Fernet را رمزگشایی می‌کند                                     |
| `find_payload(blob) -> bytes`               | داده را از بایت‌های خام فایل استخراج می‌کند                        |

برای جلوگیری از مصرف بیش‌ازحد حافظه، اندازهٔ تصویر به `MAX_IMAGE_BYTES` یعنی ۲۵۶ مگابایت و اندازهٔ داده به `MAX_PAYLOAD_BYTES` یعنی ۶۴ مگابایت محدود شده است.

## نکات امنیتی

قبل از استفاده، این چند نکته را در نظر بگیرید.

* **داده واقعاً نامرئی نیست.** چون داده بعد از `IEND` قرار می‌گیرد، ابزارهایی مثل `strings`، hex editor یا یک اسکریپت ساده می‌توانند آن را پیدا کنند. این روش برای پنهان کردن داده از نگاه معمولی است، نه مخفی کردن آن از یک تحلیل‌گر.
* **برای محافظت از محتوا از رمزگذاری استفاده کنید.** Phoenix برای این کار از Fernet استفاده می‌کند که شامل AES-128-CBC و HMAC-SHA256 است. کلیدها ۳۲ بایتی هستند و کلید اشتباه یا دادهٔ تغییرکرده رد می‌شود.
* **اگر کلید را گم کنید، داده هم قابل بازیابی نیست.** Phoenix هیچ روش بازیابی یا backup برای کلید ندارد. هر بار که داده را رمزگذاری می‌کنید یک کلید جدید ساخته می‌شود و فقط همان یک بار نمایش داده می‌شود.
* **کلید جایی ذخیره نمی‌شود.** نه داخل تصویر قرار می‌گیرد و نه در `VERSION.txt`. رابط گرافیکی فقط آن را موقتاً در حافظه نگه می‌دارد.
* **کلید را جدی بگیرید.** هر کسی که به آن دسترسی داشته باشد می‌تواند دادهٔ رمزگذاری‌شده را باز کند.
* تصاویر توسط Qt برای پنجرهٔ انتخاب فایل باز می‌شوند. Phoenix هیچ فایلی را به سرور یا سرویس دیگری ارسال نمی‌کند.

│   ├── core.py          موتور استگانوگرافی، بدون وابستگی گرافیکی

## نسخه‌بندی

نسخه در `VERSION.txt` قرار دارد و مرجع اصلی برای نسخهٔ بسته، عنوان پنجره و خروجی `phoenix --version` است.

مقایسهٔ نسخه‌ها بر اساس عدد انجام می‌شود، نه مقایسهٔ رشته‌ای. برای مثال `0.10` از `0.9` بالاتر است.

نسخهٔ منتشرشده از این مسیر خوانده می‌شود:

```text
https://raw.githubusercontent.com/AdolfMacro/phoenix/main/VERSION.txt
```

هنگام تغییر نسخه، `VERSION.txt`، `phoenix.VERSION` و مقدار نسخه در `main.py` را با هم تغییر دهید.

## اجرا از روی کلون

```bash
python3 main.py
python3 main.py --version
python3 main.py --check
```

برای اجرای مستقیم باید `cryptography` و `PyQt6` روی همان مفسر Python نصب باشند.

اگر PyQt6 نصب نباشد، `main.py` به‌جای یک `ImportError` معمولی، دستور لازم برای نصب آن را نمایش می‌دهد.

## کارایی

بخش اصلی مصرف CPU در رابط گرافیکی مربوط به انیمیشن پس‌زمینه است.

برای پایین نگه داشتن مصرف:

* تیتر درخشان فقط یک بار روی pixmap ساخته می‌شود و بعد همان تصویر دوباره استفاده می‌شود.
* اسکن‌لاین‌ها در یک لایهٔ جدا نگه داشته می‌شوند.
* دکمه‌ها تصویر وضعیت‌های مختلف خود را از قبل نگه می‌دارند.
* باران ماتریکس در بافری با حداکثر اندازهٔ ۱۶۰۰×۹۰۰ رسم و بعد بزرگ می‌شود؛ بنابراین با بزرگ‌تر شدن مانیتور، هزینهٔ پردازش بیشتر نمی‌شود.
* نرخ فریم به‌صورت خودکار تنظیم می‌شود. اگر پردازش یک فریم بیشتر از ۹ میلی‌ثانیه طول بکشد، سرعت انیمیشن کاهش پیدا می‌کند.

در اندازه‌گیری انجام‌شده روی یک پنجرهٔ تمام‌صفحهٔ ۲۳۰۴×۱۲۹۶، بازترسیم کامل حدود ۱۴ میلی‌ثانیه زمان برده و مصرف CPU هنگام اجرای انیمیشن حدود یک‌سوم یک هسته بوده است.

# phoenix

**Թաքցրեք տվյալները PNG պատկերների ներսում:** ստեղանոգրության գործիք՝ լիարեկան էկրանով տերմինալային հերթակայված գրաֆիկական ինտերֆեյսով:

Phoenix-ը ձեր տվյալները ավելացնում է PNG ֆայլի `IEND` բլոկից հետո։ Պատկերի ինքները չեն վնատվում, ուստի կրողների պատկերը միշտ բացվում է սովորական դիտիչում, իսկ տվյալները կարող են նաև գաղտնագրվել Fernet բանալիով:

```
phoenix          # բացել գրաֆիկական ինտերֆեյսը՝ լիարեկան
phoenix --help
phoenix --version
phoenix --check  # համեմատել հրապարակված տարբերակի հետ
```

![Phoenix-ի գրաֆիկական ինտերֆեյսը](https://github.com/AdolfMacro/phoenix/blob/main/screenshots/1.png?raw=true)

## Ինչպես է աշխատում

PNG ֆայլը բլոկների հաջորդականություն է:

```
89 50 4E 47 0D 0A 1A 0A   ֆայլի ստորագրում
IHDR ...                    պատկերի վերնագիր
IDAT ...                    սեղմված պիքսելները
IEND AE 42 60 82            ավարտի նշանը
<ձեր տվյալները>           ավելացվում են այստեղ
```

`phoenix/core.py`-ը իրական բլոկային կառուցվածքն անցնում է քայլ առ քայլ՝ կարդալով յուրաքանչյուր բլոկի չորս բայտանոց երկարության դաշտը և առաջ շարժվելով՝ մինչև կհանդիպի `IEND`-ին, որից հետո ամեն ինչը, որ գալիս է, վերադառնում է որպես թաքցրված տվյալ։

Կառուցվածքը սկսում ենք շուտում `IEND` բայտային նախաշինը փնտրելու փոխարեն, ինչն ունի երկու կարևոր առավելություն.

- Այն տվյալը, որը ինքը `IEND` նախաշինն ունի, **ամբողջությամբ** պահվում է և կարդում՝ առանց ստորագրի հեռակետիկում.
- Կտրված, վերաձևագծված կամ PNG չհետևող ֆայլը մերձ հստակ հաղորդագրությամբ մերժվում է, ոչ թե մի raw `IndexError` բեկեկ.

Եթե նոր տվյալ եք կապում արդեն տվյալ պահող պատկերին, տվյալները կրկնվում են՝ վերջինը կարդացվում է կարդացողին։ Չի թույլատրվում գրել նույն ֆայլի վրա, որը հիմա կարդում եք։

## Տեղադրում

```bash
git clone https://github.com/AdolfMacro/phoenix.git
cd phoenix
bash installer.sh
```

Գործարկեք **սովորական օգտագործողով**՝ սցենարը `sudo` թույլությունն է հարցում ինքը։ Այն տեղադրում է կոդը `/usr/src/phoenix` պատկերում և ստեղծում է գործարկիչ `/usr/local/bin/phoenix`։

### Կախվածությունները և PEP 668

Դեբիանի, Ուբունտուի, Ֆեդորայի և Արխի նոր տարբերակներում համակարգային տարբերակողը նշված է որպես *արտաքին կառավարվող*, ուստի `pip install` դրա վրա՝ `--user` կողպեքով թե առանց դրա, `externally-managed-environment` սխալով մերժվում է։ Phoenix-ը ընդհանրապես չի փորձում դա․ տեղադրիչը ընտրում է առաջին աշխատող տարբերակը․

1. **Տարբերակով, որն արդեն ունի երկու փաթերը։** Ոչինչ չի տեղադրվում։
2. **Դիստրիբուտիվ փաթերները**, եթե առկա է փաթերների կառավարիչ (`apt-get`, `dnf`, `pacman`, `zypper`)՝ `python3-cryptography` և `python3-pyqt6`։
3. **Մասնավոր վիրտուալ միջավայր (venv)**՝ `/usr/src/phoenix/.venv` ուղիով։

Եթե պետք է ընտրությունը փոխել՝

```bash
PHOENIX_DEPS=venv    bash installer.sh   # միշտ վիրտուալ միջավայր
PHOENIX_DEPS=distro  bash installer.sh   # միայն դիստրիբուտիվ փաթերները
PHOENIX_DEPS=system  bash installer.sh   # միայն արդեն աշխատող տարբերակով
PHOENIX_PYTHON=/path/to/python3 bash installer.sh
PHOENIX_PREFIX=~/.local/share/phoenix PHOENIX_BINDIR=~/.local/bin bash installer.sh
```

Տեղադրիչը կրկնվող գործարկումն անվտանգ է․ գոյում վիրտուալ միջավայրը չի վերակառուցվում, իսկ գործարկիչը միշտ պահում է տարբերակի բացարձակ ուղիը։

### Հեռացում

```bash
sudo rm -rf /usr/src/phoenix /usr/local/bin/phoenix
sudo rm -rf /usr/src/phoenix/.venv      # միայն եթե վիրտուալ միջավայր էր ստեղծվել
```

## Գործիրիկում գրաֆիկական ինտերֆեյսով

Պատուհանը բացվում է **լիարեկան**։ Չորս էջ հասանելի են ձախ ցանկից․

| Ստեղն | Գործողություն |
| --- | --- |
| `1` … `5` | անցնել էջերի միջև (1–4՝ էջեր, 5՝ ելք) |
| `F11` | անցնել լիարեկանից սովորական պատուհան |
| `ESC` | դուրս գալ լիարեկան ռեժիմից |
| `CTRL+Q` | փակել ծրագիրը |

`CTRL+C`-ը նույնպես մաքուշ, առանց որևէ հետքետի, փակում է ծրագիրը։

### 1 · Կապում

Ընտրեք կրող PNG պատկեր, գրեք կամ բեռնեք տվյալները և գրեք արդյունքը։ «Գաղտնագրել տվյալները նոր Fernet բանալիով» նշիչը հեռացնում է բանալի, որը ցույց է տրվում մեկ անգամ. **պահեք այն, սա տվյալները վերականգնելու միակ ձևն է**։ Արդյունքի անունը նախապես լցվում է որպես `<name>_phoenix.png`։

### 2 · Կարդում

Ընտրեք Phoenix-ի ստեղծած պատկերը։ Տեղեկության տողը ցույց է տալիս պատկերի չափը, թաքցրված տվյալի չափը և գաղտնագրված է, թե ոչ։ Եթե բանալի է կիրառվել, նշեք «Թաքցրված տվյալները գաղտնագրված են» և պահեք բանալին։ Վերականգնված տեքստը կարելի է պատճենել կամ պահել։

### 3 · Մշակող

Հեղինակի տվյալները, հղումները և դյուրիկ նկարահայտում տերմինալի վերաբերյալը։

### 4 · Թարմացում

Համեմատում է տեղական `VERSION.txt`-ը GitHub-ի հրապարակվածի հետ և հաղորդում է, թե վերջինն եք, հետբերավ թե, թե առաջ եք։ Թարմացումը կիրառելու համար նորից աշխատեցվում է տեղադրիչը, որը պետք է `sudo`։

Պատուհանի ներքևի տերմինալը գրանցում է ամեն գործողությունը՝ ժամանակի մասնագրով։

## Մոտորի ուղղակի կիրառում

`phoenix.core` մոդուլը գրաֆիկական ինտերֆեյսից կախված չէ և `cryptography`-ից դուրս ոչինչ չի ներմուծում.

```python
from phoenix import core

key = core.generate_key()                       # 44 URL-անվատեղական նիշ
token = core.encrypt_payload("secret", key)     # վերադարձնում է Fernet թոկեն

core.bind("cover.png", "cover_phoenix.png", token)   # գրված բայտների թիվ
core.read("cover_phoenix.png")                       # ինքն թոկենը
core.read("cover_phoenix.png", key)                  # «secret»
```

`read(source, key=None)`-ում բանալիի բացակայությունն տարբերվում է դրա դատարկությունից․ `None`-ը նշանակում է՝ «այս տվյալը չգաղտնագրված է», իսկ ցանկացած տողային՝ նույնիսկ `""`-ը, նշանակում է՝ «գաղտնագրազերծ դրանով»։ Այսպես բացակայող բանալին հաղորդվում է, և չգաղտնագրված տվյալը չի ներկայացվում որպես հաղորդական տեքստ։

Ցանկացած ձախողություն բացատրում է `PhoenixError`՝ մարդկուս համար գրված հաղորդագրությամբ․

```python
>>> core.read("notes.txt")
PhoenixError: This file is not a PNG image. Only PNG files are supported.

>>> core.read("bound.png", "wrong-key")
PhoenixError: Wrong decryption key, or the payload was altered.
```

### Ծերսակ

| Ֆունկցիա | Նպատակ |
| --- | --- |
| `bind(source, destination, payload) -> int` | տվյալը գրում է պատկերի պատճենի մեջ և վերադարձնում է բայտների թիվ |
| `read(source, key=None) -> str` | վերադարձնում է տվյալը, բանալիի դեպքում գաղտնագրազերծելով |
| `inspect(source) -> dict` | պատկերի չափը, տվյալի չափը և գաղտնագրված է, թե ոչ |
| `is_png(path) -> bool` | կառուցվածքի ստուգում՝ առանց սխալի |
| `validate_png(path) -> Path` | կառուցվածքի ստուգում՝ `PhoenixError` վերաձևագծելով |
| `generate_key() -> str` | նոր Fernet բանալի |
| `encrypt_payload(plaintext, key) -> str` | գաղտնագրում է Fernet թոկենում |
| `decrypt_payload(token, key) -> str` | գաղտնագրազերծում է Fernet թոկենը |
| `find_payload(blob) -> bytes` | տվյալն հանում է ֆայլի չմշակված բայտերից |

Անվտանգության սահմանափակումներ․ `MAX_IMAGE_BYTES`-ը 256 ՄԲ է, իսկ `MAX_PAYLOAD_BYTES`-ը՝ 64 ՄԲ․ ավելի մեծ մուտքերը մերձվում են, քան կոշկ, բեռնվում հիշում։

## Անվտանգության նկատառումներ

Նախքան հենվել գործիրիկի վրա, կարդացեք այս բաժինը։

- **Տվյալը չէ թաքցվում նրանից, ով ուշադիր է նայում**։ Այն տեղակայվում է վերջին բլոկից հետո, ուստի `strings`-ը, hex խմբագրիչը կամ ցանկացած սցենար, որը կարդում է `IEND`-ից հետո, կգտնի այն։ Ստեղանոգրությունը տվյալը թաքցնում է սովորական դիտումից, ոչ թե վերլուծաբանից։
- **Կոդավորումն է կարևոր մասը**։ «Գաղտնագրել տվյալները» նշիչը մինչեւ տվյալը պահում է Fernet՝ AES-128-CBC՝ HMAC-SHA256 վերիֆիկացիամբ, բանալիները 32 բայտանոց են, և սխալ բանալի կամ փոխված տվյալ մերձվում է, քան վերադառնում անիմաս տվյալ։
- **Բանալին կորցնելը նշանակում է տվյալը կորցնել**։ Ոչ մի վերականգնման ճանապարհ կա, ոչ էլ բանալիների պահուստ։ Ամեն կապումից նոր բանալի է ստեղծվում և ցույց է տրվում մեկ անգամ։
- **Բանալին երբեք չի պահվում** ոչ պատկերի մեջ, ոչ էլ `VERSION.txt`-ում․ ինտերֆեյսն այն պահում է միայն հիշումքում և պատճենահնում ձեր բուֆերին՝ ձեր անունով դիսկի որևէ բան չգրելով։
- **Բանալին հենց այնպես է լինում, եթե զգուշությամբ չեք պահում**։ Գտնեք հենց գործիչներով վերաբերվեք։
- Պատկերները բացում է Qt-ն՝ ֆայլեր ընտրելու պատուհանների համար․ Phoenix-ը ոչինչ ոչ մի տեղ չի բեռնում։

│   └── updater.sh       գոլործում է թորհը և նորից աշխատեցնում տեղադրիչը

## Տարբերակավորում

Տարբերակը պահվում է `VERSION.txt`-ում և հանդիսում է միակ աղբյուրը փաթեթի, պատուհանի վերնագրի և `phoenix --version` հրամայի համար։

Տարբերակները համեմատվում են ըստ իրենց թվային նիշերի (`0.2:1`՝ `[0, 2, 1]`), ոչ թե որպես տողեր, ուստի `0.10`-ը ճիշտ է բարձր է `0.9`-ից, իսկ `0.2:1`-ը՝ `0.0.1:0`-ից։ Հրապարակված պատճենը բեռնվում է հետևյալ հասցեով․

```
https://raw.githubusercontent.com/AdolfMacro/phoenix/main/VERSION.txt
```

Փոխեք `VERSION.txt`-ը, `phoenix.VERSION`-ը և `main.py`-ի սահմանաչափը միասին։

## Գործարկում կլոնից

```bash
python3 main.py           # գրաֆիկական ինտերֆեյս
python3 main.py --version
python3 main.py --check
```

Պետք է `cryptography` և `PyQt6` այն տարբերակով, որով կգործարկում եք։ Եթե PyQt6-ը բացակայում է, `main.py`-ը փոխարեն մանրանկար `ImportError`-ի՝ տեղադրման ճշգրիտ հրամանն է տպում։

## Կատարողակնության նկատառումներ

Գրաֆիկական ինտերֆեյսի միակ իսկապես թանկ մասը լիարեկան ֆոնային անիմացիան է։ Այն մնում է ոչ թե թանկ, հենց դրա համար․

- Վառացող վերնագիրը միայն **մեկ անգամ** է պատկերվում pixmap-ում և հետո պարզումի է պատկերով․ թարմացումը մեկ կիսաթափով՝ տարսությամբ։
- Սկանագծերը պահված շերթ են, որը բեռնվում է մեկ զանգով։
- Կոճակները պահում են իրենց պատկերը ըստ վիճակի (սերմույց, սեղմում, անունակություն, կենտրոնացում)։
- Տեղանոնը պատկերվում է առավելագույնը 1600×900 չափով բուֆերում և մեծացվում է, ուստի արժենը չի աճում էկրանի չափի հետ, և **ինքն է կարգավորում իր կադրի արագությունը**. եթե մեկ կադրը տևում է ավելի քան 9 միլիվարկոնդ, այն դառնում է դանդաղ։

Չափումները անգործիշ լիարեկան պատուհանի վրա՝ 2304×1296 չափով․ ամբողջական վերանկարումը տևում է մոտ 14 միլիվարկոնդ, և ծրագիրը անիմացիայի ընթացքում սպառում է մոտ մեկ երրորդը մի պրոցեսորի ենթամիությունը։
